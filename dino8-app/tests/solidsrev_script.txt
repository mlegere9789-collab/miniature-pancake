# Exact revolved-solid editing QC (see the "SR" section at the end of smoke.sh).
#
# Closes two sub-gaps of "Solid editing with B-rep results (booleans, fillet,
# shell, offset)": OffsetSrf Solid=Yes on a plain capped cylinder, and
# OffsetSrf / Shell on a plain capped CONE and CONE FRUSTUM (Cone / TCone), all
# of which used to give meshes. Every case starts from `New` and is bracketed by
# an unknown-command marker line ("SRBEGIN_<name>") that smoke.sh uses to slice
# the output into per-case blocks. Each case ends with List, Volume and Check on
# the result so the smoke checks read measured numbers against closed forms.
# NB the app's Cone puts its APEX at the clicked base point and the flat cap at
# z = height, so the cap of "Cone 0,0,0 5 10" is clicked at 2,0,10.
SetActiveViewport Top
