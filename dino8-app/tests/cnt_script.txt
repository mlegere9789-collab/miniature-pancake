# G0 / G1 / G2 continuity options of Loft, Patch and NetworkSrf, and the MeasureEdgeContinuity report (see the "CNT_"
# section at the end of smoke.sh). Every case starts from `New` and is bracketed by a marker line ("CNTBEGIN_<name>",
# an unknown command) that smoke.sh uses to slice this script's output into per-case blocks.
#
# Adjacent surface everywhere: Plane -10,0,0 0,10,0 (flat z = 0, degree 1 x 1; its x = 0 edge is the edge to continue; a
# click at -1,5,0 picks that edge). Every continuity angle / curvature below is MEASURED by the kernel
# (NurbsSurface::MeasureEdgeContinuity, evaluating both surfaces at probe points on the edge) - never inferred.
#
# Loft fixture L: sections z = 0.004 x^2 sampled at x = 0 (the edge), 5, 10 (z = 0, 0.1, 0.4): a parabola leaving the plane
# tangentially, but the loft's own chord-length parameterisation makes the plain interpolating surface leave the edge at
# 6.4e-5 rad. Patch fixture P: the edge line plus two points at (10, y, 0.5): the plain least-squares fit is the tilted
# plane z = 0.05 x (0.05 rad to the flat plane). Network fixture N: four Bezier curves, the two crossing the edge have zero
# slope there (z controls 0, 0, 0.2, 0.5), so the exact Coons patch is already G1 - a negative control for "the option
# changes nothing when the data already agree".
