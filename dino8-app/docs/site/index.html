What Dino 8 is

Dino 8 is a free desktop 3D modeler built on the dino8-kernel geometry library (OpenNURBS for NURBS/B-rep/.3dm, Manifold for watertight mesh booleans) with a Dear ImGui + GLFW interface. It runs on Windows, Linux, and macOS from one code base, with no subscription, no account, and no telemetry.

Where these docs come from

The command reference is generated by dino8-app/docs/gen_command_docs.py directly from data/commands.json (the 1055-command Rhino 8 catalog) and the actual Reg(...) registration calls in src/commands/cmd_*.cpp, so its Implemented/Partial/Planned status can never drift from the real build. Every tutorial's command sequence was run through the real Dino8 binary with --smoke N --script <file> and its @expect_objects checks, the same way the project's own regression suite works — see Tutorials for the verification note on each one.

Dino 8 is free software with no telemetry. This site is static HTML/CSS/JS with no build step — open any page directly in a browser, or serve dino8-app/docs/site/ with any static file server.
