# History persistence, part 1 (tests/smoke.sh section HPS_): construction history
# is written into the .3dm ("Dino8.HistoryMeta") and comes back after Save/New/Open.
# This script builds three documents and saves each (@TMP@ is the test temp dir):
#   OFF  History Off while building -> nothing recorded (negative control)
#   DEL  History On, then the root curve is deleted before Save (dangling source)
#   ON   History On: curve -> Extrude -> OffsetSrf, and curve -> Extrude ->
#        BooleanIntersection with a box. A throw-away box is built and deleted
#        first so the saved object ids are NOT 1,2,3...: the reopened document
#        must remap them (the file stores object uuids, Open assigns fresh ids).
# ON is last; it is then reopened in this same process (New, Open) and its source
# curve is moved - the dependents must follow with no UpdateHistory call.
