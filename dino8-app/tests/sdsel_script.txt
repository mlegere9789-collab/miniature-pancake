# Select a SubD's control-net edges / vertices by type. Each case prints the number of matching elements on its first line

# 0,0,0 - 20,20,0 (a 4 x 4 grid of cells, each split into two triangles).
# smoke.sh runs this script; there is no @TMP@ substitution here.
