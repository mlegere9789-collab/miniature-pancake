# History / UpdateHistory extended to Sweep1 (Sweep1Command, cmd_surface.cpp;
# RebuildSweep1, history_rebuild.h), single-cross-section case only: the same
# source-curve-moves -> UpdateHistory-rederives loop history_script.txt and
# history_pipe_script.txt already prove for Extrude/Revolve/Loft/SubDLoft/
# Pipe, now for Sweep1 as a seventh tracked command - see cmd_history.cpp's
# own header comment for the full scope list. The money check is a real
# bounding-box move, not just an object count, so a fake/no-op rebuild would
# fail this the same way it would in history_script.txt/history_pipe_script.txt.
#
# The section curve (not the rail) is the one moved here, deliberately: the
# kernel's own exact Brep::Sweep1 carries the section RIGIDLY along the
# rail's frames, preserving its offset from the rail's own current start
# point (see brep.h's own Sweep1 doc comment) - so translating the RAIL
# alone by a pure offset, with the section left untouched, exactly cancels
# out in the rebuilt result (the recomputed offset absorbs it) and would be
# a false-negative-proof test, not a real one. Moving the section instead
# has no such cancellation and gives an unambiguous, real geometry change.
#
# Object ids below are the deterministic 1-based counter Document::Add
# assigns, in creation order.
