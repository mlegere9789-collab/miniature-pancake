# Automatic history propagation + EditHistory (cmd_history.cpp, Document::
# JoinPendingChange). With History On, editing a SOURCE object (here: Move and
# Scale of a curve, Delete, Undo/Redo) rebuilds every recorded dependent in
# dependency order inside the SAME undo step - no UpdateHistory call anywhere in
# sections A. Every claim is a measured Volume / Bounding box / Length / Area.
#   A1  curve -> Extrude -> OffsetSrf (2-deep chain): Move, Scale, Undo, Redo
#   A2  curve -> Extrude -> BooleanIntersection (boolean chain)
#   A3  failure: the root curve is deleted (reason printed, dependents keep
#       their geometry); Undo of the Delete
#   A4  History Off: nothing propagates; UpdateHistory still works on demand
#   A5  an unrelated edit rebuilds nothing
#   E   EditHistory: change the recorded options of a construction (extrude
#       distance/bothsides, tapered draft, revolve angle, pipe radius, loft
#       style, offset distance, boolean operation/swap), measured before/after,
#       validation, one undo step, dependents follow
