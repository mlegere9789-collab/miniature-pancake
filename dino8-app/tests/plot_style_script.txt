# PlotStyleTable/LayerPlotStyle command-line wiring (PARITY_MAP.md "Print
# and plot output" item - the actual "no named, reusable plot style table"
# gap left open after LayerPrintWidth/LayerPlotColor closed the per-layer
# lineweight/color overrides). The pure LayerPrints/EffectivePrintWidthMm/
# EffectivePlotColor `style` resolution itself is unit-tested directly in
# dino8_plot_style_table/test_plot_style_table.cpp; this instead exercises
# the real scriptable commands end to end, through a real ExportSvg call.
#
# A Line on the Default layer (display color black, the default) exported
# to SVG with no plot style assigned must stroke black at the document
# default width (0.25mm); defining a named style "Mono" (red, 0.75mm) and
# assigning it to the layer must make the SAME layer's re-export stroke red
# at 0.75mm - a named table entry, not a second independent per-layer
# field - and clearing the assignment back to ByLayer must return to black
# at the default width.
# @TMP@ is replaced by smoke.sh with a scratch directory.
Line 0,0,0 10,0,0
SelLast
Export @TMP@/plot_style_off.svg
PlotStyleTable
Mono
255,0,0
0.75
LayerPlotStyle Mono
SelLast
Export @TMP@/plot_style_on.svg
LayerPlotStyle ByLayer
SelLast
Export @TMP@/plot_style_cleared.svg
