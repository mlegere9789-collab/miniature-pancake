# A constant-radius rolling-ball blend PATCH between two surfaces: a new surface object, the parents are left alone. The two picks
# choose the ball sides. Every case starts from `New` and is bracketed by a marker line ("FSRBEGIN_<name>", an unknown command)
# that smoke.sh uses to slice this script's output into per-case blocks.
#
# Fixtures
#  floor/wall planes (analytic): floor z = 0, x 0..20, y 0..10; wall x = 0, y 0..10, z 0..10. Radius r ball in the corner: centre
#    line x = r, z = r, contacts (r, y, 0) and (0, y, r); the blend is a quarter cylinder with bounding box x 0..r, z 0..r.
#  curved: a floor lofted through 4 control-point sections (z = 0.3 sin(x/3) cos(y/4) at the CVs) and a leaning wavy wall lofted
#    through 4 sections (x = 4 + 0.4 sin(y/2) + 0.1 z), crossing the floor near x = 4.3.
