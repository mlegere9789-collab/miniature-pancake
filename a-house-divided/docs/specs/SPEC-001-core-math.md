# SPEC-001: core-math (deterministic arithmetic and random streams)

Crate: `crates/core-math`. No dependencies except `proptest` (dev). `#![forbid(unsafe_code)]`.
Goal: arithmetic and randomness whose results are bit-identical on every platform, compiler
and optimisation level, with no floating point in the authoritative path.

## 1. Fixed point `Fx` (Q32.32 in `i64`)
The stub in `src/lib.rs` fixes the type, `from_raw`, `raw`, `ZERO`, `ONE`, `FRAC_BITS`. Keep them.
Behaviour must be identical in debug and release: never rely on overflow panics or wrapping defaults.

| Operation | Definition |
|---|---|
| `Add`, `Sub`, `Neg` | saturating at `i64::MAX` / `i64::MIN` raw (`-MIN` saturates to `MAX`) |
| `Mul` | `((a as i128 * b as i128) >> 32)` using arithmetic shift (floor), then saturate to `i64` |
| `Div` | `((a as i128) << 32) / (b as i128)` truncating toward zero; `b == 0` gives `MAX` if `a > 0`, `MIN` if `a < 0`, `ZERO` if `a == 0` |
| `abs`, `min`, `max`, `clamp`, `signum` | exact; `abs(MIN)` saturates |
| `from_int(i32)`, `to_int_floor`, `to_int_round_half_up` | exact definitions, tested at the extremes |
| `sqrt` | floor of the square root, integer-only (Newton iteration on `u128`); negative input returns `ZERO` |
| `Fx::from_f64`, `Fx::to_f64` | behind cargo feature `float-io` (off by default), for visuals and tests only; the crate itself never uses them |

Constants required: `PI`, `TAU`, `HALF`, `EPSILON` (raw 1), `MAX`, `MIN`.

## 2. `Angle`
`Angle(u32)`: a full turn is 2^32. Wrapping add/sub is intended. Provide `from_turns_fraction`, `from_degrees_int`, `to_fx_radians`.
`sin`, `cos` (returning `Fx`) by table lookup with linear interpolation. The table must be generated by integer-only code
(committed as a const array plus a test that regenerates it) or computed once offline and committed. `atan2(y, x) -> Angle`
integer-only (CORDIC or table-based). Accuracy targets, checked in tests against `f64` (tests may use floats):
`|sin|,|cos|` error below 2^-20; `atan2` error below 2^-18 turns.

## 3. `Vec2Fx`
Keep the stub fields. Add: `new`, `ZERO`, `Add`, `Sub`, `Neg`, `scale(Fx)`, `dot`, `cross`, `length_sq`, `length` (uses `sqrt`; must not overflow
for components up to 2^30 in magnitude: use `i128` internally), `distance_sq`, `normalize` (zero vector returns zero), `rotate(Angle)`,
`from_angle(Angle)`, `lerp`.

## 4. Random streams
Algorithm: xoshiro256** seeded through SplitMix64 (both published, public-domain algorithms; implement them in this crate, no external crate).
- `RngStreams::new(master_seed: u64)`; `stream(&self, id: StreamId) -> Rng` derives an independent generator from `(master_seed, id)` by SplitMix64 mixing.
  `StreamId` is a `u32` newtype. Deriving a stream never mutates `RngStreams`; adding a stream never changes another stream's output.
- `Rng`: `next_u64`, `next_u32`, `range_u32(lo, hi)` (unbiased, rejection or Lemire's method, half-open), `range_i32`, `unit_fx()` in `[0, 1)`,
  `coin(num, den)`, `shuffle<T>(&mut [T])` (Fisher-Yates), `state() -> [u64; 4]`, `from_state([u64; 4])`.
- `Rng` is `Clone` and its state round-trips exactly.

## 5. Tests (written first by a separate agent where possible; the implementer may add more but not weaken these)
1. **Golden vectors** for SplitMix64 and xoshiro256** (first 16 outputs for seeds 0, 1, 0xDEADBEEF) as literal constants in `tests/golden.rs`.
2. **Platform checksum:** a fixed pseudo-random sequence of 1,000,000 mixed `Fx` and `Vec2Fx` operations folded into a single `u64`; the literal expected
   value is checked in. (This is what cross-platform CI compares.)
3. **Properties (proptest):** add/sub inverse when no saturation; mul commutative; `x * ONE == x`; `(x / y) * y` within one ulp when no saturation;
   `sqrt(x)^2 <= x < (sqrt(x)+1)^2`; sin^2+cos^2 within 2^-18; `normalize` length within 2^-20 of one; angle wrap; stream independence
   (adding a stream does not change another); `range_u32` stays in range and is uniform within statistical tolerance over 1,000,000 draws.
4. **Edge cases:** every operation at `MIN`, `MAX`, `ZERO`, `-1`, and division by zero, with exact expected values.
5. Doc tests for every public function.

## 6. Done when
`cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` pass; no `unsafe`; no `f32`/`f64` outside
`#[cfg(test)]` and the `float-io` feature; public items documented; the stub's public surface unchanged.

## Amendment A1 (from independent review, cycle 01)
`Rng::from_state` keeps its signature for existing callers but is documented as substituting the seed-0 state for the invalid all-zero state; a new `Rng::try_from_state([u64; 4]) -> Option<Rng>`
returns `None` for the all-zero state and is the exact round-trip API. `coin(num, den)` with `num >= den` consumes no random draw and returns true; `num == 0` consumes none and returns false (tests pin both).
