# Rolling-ball fillet of the SADDLE edge of a perpendicular pipe tee (see the "PTF_" section at the end of smoke.sh).
#
# kernel::FilletPipeTee is wired into FilletEdge (cmd_fillet.cpp TryPipeTeeFillet / OnPipeTeeSaddle) as the last exact
# attempt, after the capped-cylinder / frustum, hole-plate and revolve-rim paths declined. The solid is the app's own
# sealed Boolean union (TryGeneralBrepBoolean) of a main cylinder (radius R = 2, axis z, z = -3 .. 3) and a branch
# cylinder (radius rb = 1, from the axis crossing along +y to y = 5, ending in its own planar cap). The branch is the
# second Cylinder (axis z) turned with Rotate3D about the x axis by -90 degrees: a branch turned about y, or one whose
# seam lies on the saddle curve (a further 90 degrees about z first), is declined by the Boolean engine itself.
#
# Picks: FilletEdge picks the edge nearest the point on the construction plane (z = 0 in the Top viewport), so the
# saddle is picked where it crosses z = 0: (+-1, sqrt(3), 0) (x^2 + y^2 = R^2 and x^2 + z^2 = rb^2).
#
# Every case starts from `New` and is bracketed by a marker line ("PTFBEGIN_<name>", an unknown command) that smoke.sh
# uses to slice this script's output into per-case blocks.
