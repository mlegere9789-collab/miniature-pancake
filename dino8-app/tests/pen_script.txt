# SetObjectDisplayMode Pen/Arctic QC: two distinctly-coloured boxes in a
# Shaded (never Pen/Arctic) Top view. Box A (screen-left, red) is left alone
# throughout; Box B (screen-right, blue) gets the Pen override toggled on
# then off, then the Arctic override toggled on then off - two more real
# per-object fill-colour/lit overrides (see Viewport.cpp's force_pen/
# force_arctic handling and SetObjectDisplayModeCommand), honoured even
# though the viewport itself is never switched to Pen or Arctic. SelNone
# before every capture so the selection-colour tint never muddies the
# sample. This script only builds the scene and captures screenshots;
# smoke.sh does the actual pixel-level verification.
# @TMP@ is replaced by smoke.sh with a scratch directory.
Box -20,-5,0 -10,5,0 5
SelLast
SetRenderColor 230,30,30
Box 10,-5,0 20,5,0 5
SelLast
SetRenderColor 30,30,230
SelNone
ShadedViewport
Top
ZoomExtentsAll
ViewCaptureToFile @TMP@/pen_off.bmp
SelID 2
SetObjectDisplayMode Pen
SelNone
ViewCaptureToFile @TMP@/pen_on.bmp
SelID 2
SetObjectDisplayMode UseViewport
SelNone
ViewCaptureToFile @TMP@/pen_off2.bmp
SelID 2
SetObjectDisplayMode Arctic
SelNone
ViewCaptureToFile @TMP@/arctic_on.bmp
SelID 2
SetObjectDisplayMode UseViewport
SelNone
ViewCaptureToFile @TMP@/arctic_off2.bmp
@expect_objects 2
