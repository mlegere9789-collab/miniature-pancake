# Revolve Angle/StartAngle: RevolveCommand (cmd_solids.cpp) now exposes
# Angle and StartAngle options (degrees), neither previously available
# anywhere in the app. A genuinely non-default combination (Angle != 360
# and/or StartAngle != 0) routes RebuildRevolve through
# kernel::Brep::Revolve (brep.h), which has supported both since before
# the app exposed either; the plain default full 0..360 revolve (the
# overwhelmingly common case, and the only one this command has ever
# built) is left on the exact same pre-existing ON_BrepRevSurface
# construction, untouched.
#
# Note: a partial-angle revolve's own two planar pie-slice end caps hit
# the same pre-existing app-level mesh-closure gap already disclosed for
# ExtrudeCrvToPoint's cone and the plain full-Revolve cylinder case (see
# extrude_to_point_solid_script.txt's own header comment) - Volume reports
# it as not-closed/zero despite List/Check correctly treating it as a
# genuine closed solid. A full revolve at a nonzero StartAngle has no such
# gap (same single doubly-periodic-face torus topology as the default
# case), so Volume measures it directly there.
