# History / RecordHistory / UpdateHistory: a real, intentionally-scoped
# constructional-history mechanism for Extrude/ExtrudeCrv, ExtrudeCrvToPoint,
# Revolve, Loft and SubDLoft (see cmd_history.cpp's own header comment for
# exactly why this set and the honest scope limit versus every other
# construction command). This script proves the whole loop for real:
#  - History defaults Off: a construction command's result carries NO
#    recorded history - UpdateHistory finds nothing to redo for it.
#  - History On: the SAME construction, run again, DOES get a HistoryRecord
#    (source curve id + parameters).
#  - Moving the source curve, then running UpdateHistory, genuinely
#    re-derives the dependent surface's geometry (a real bounding-box
#    check, not just an object count) from the curve's NEW position - the
#    exact check that would catch a fake/no-op implementation.
# Object ids below are the deterministic 1-based counter Document::Add
# assigns, in creation order (see provenance_script.txt's header comment
# for the same assumption).

# --- History defaults Off: Extrude while off records nothing, so
# UpdateHistory has 0 objects to redo.
History

SelNone

5

UpdateHistory
History

# --- History On: a fresh Extrude DOES get tracked.

# surface (id 4) is NOT touched by Move itself, so its bounding box must

RecordHistory Off

# --- Undo must never let a NEW object reuse an undone object's id. The
# HistoryRecord side table (like Provenance/HoleFeature/PipeFeature/
# SymmetryLink) is keyed by ObjectId and deliberately not part of the undo
# history, so before Document::ApplyDelta kept the id counter monotonic a
# Box drawn right after undoing a tracked Extrude was handed the undone
# extrusion's own id (6 here), History listed the Box as "object 6: Extrude
# <- 5", SelExtrusion selected it, and UpdateHistory silently rebuilt the
# user's Box into the extrusion of line 5. Now the Box must get a fresh id
# (7), UpdateHistory must report the undone extrusion's record as orphaned,
# and the Box's own geometry must be untouched.
History On

5
@expect_objects 6
