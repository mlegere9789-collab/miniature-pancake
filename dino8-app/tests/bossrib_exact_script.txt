# Boss / Rib through the exact kernel route (the "BRX_" section, tests/sections/82_bossrib_exact.sh).
#
# BossRibCommand used to build every Boss/Rib as a mesh loft and fuse it with a MESH boolean. It now calls kernel::MakeBoss /
# kernel::MakeRib first (exact B-rep fusion of the swept footprint / web onto the base solid) and falls back to the mesh construction
# only when the kernel refuses, printing why. Expected values are closed forms of the fixture, independent of the app's printout:
#   plane boss : box 10 x 10 x 10 (volume 1000) + a r = 2 circle on its top face raised 5      -> 1000 + pi 2^2 5 = 1062.83
#   plane rib  : box 10 x 10 x 10 + a straight 6-long spine on its top face, height 2, thickness 1 (default) -> 1000 + 6 x 2 x 1 = 1012
#   fallback   : a curved (arc) rib spine is not a straight line, so the kernel declines and the mesh construction runs
#   plane pocket : the same box, a r = 2 circle on its top face cut 3 deep                -> 1000 - pi 2^2 3 = 962.30
#   sphere pocket: a ball of radius 5 (523.60), a r = 1.5 circle at its pole cut 1 deep (floor z = 4)
#                  -> 523.60 - [(2 pi / 3)(5^3 - (5^2 - 1.5^2)^(3/2)) - 4 pi 1.5^2] = 523.60 - 6.261 = 517.34
#   pocket fallback: an OPEN (arc) footprint is refused by the kernel, the mesh boolean runs and the message names the reason
