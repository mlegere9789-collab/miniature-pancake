# BooleanUnion / BooleanDifference / BooleanIntersection on two SubDs (the "SDB_" section, tests/sections/82_sdbool.sh).

# The app's SubD booleans now choose the refinement per operand (kernel SubD::BooleanSubD semantics): an operand that is exactly its cage (a fully
# creased box) is used at level 0, any other is refined by the Levels option (0 = automatic by face count). The status line reports the rounds used
# per operand, the seam creases and the result's control-net volume. Fixture: two fully creased SubD boxes, A = [0,10]^3 and B = [5,15]^3, which
# are exactly the solid boxes (overlap [5,10]^3 = 125): union 1000 + 1000 - 125 = 1875, intersection 125, A - B = 875, B - A = 875. The app's Volume
# of a SubD reads the control net, which for a fully creased result equals the limit volume.
# SubDBox places its base corners on the active CPlane (the z of the typed corners is projected to the CPlane, as for Box), so box B is built at
# z = 0..10 and then moved up by (0,0,5) to occupy [5,15]^3; typing 5,5,5 15,15,5 gives [5,15]x[5,15]x[0,10], whose overlaps with A are 250 / 1750 / 750.
