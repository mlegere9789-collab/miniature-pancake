# ExtrudeCrvAlongCrv Solid option (tests/smoke.sh section XAL_): the kernel's exact Brep::ExtrudeAlongCurve (translational sum
# surface, profile never rotates; rational profiles/paths exact; closed path + open profile = periodic sheet; refusals carry
# their reason and build nothing). Cases, in order (smoke.sh cuts the output at each "Command: ExtrudeCrvAlongCrv"):
#  1 circle r=2 (XY) along a line z=0..5, Solid=Yes: the cylinder, volume pi 4 5 = 62.8319
#  2 circle r=1 (XY) along an EIGHTH-circle ARC (rational) in XZ, centre origin, radius 3, from (3,0,0) to (3 cos 45, 0, 3 sin 45):
#    volume pi * (net z = 3 sin 45 = 2.12132) = 6.66432. The arc is drawn in the Top viewport as `Arc 0,0,0 3,0,0 3,3,0` (the Arc
#    command works in the construction plane: the end POINT only gives the end angle, here 45 degrees) and turned into XZ with
#    Rotate3D about the x axis. (The earlier `Arc 0,0,0 3,0,0 0,0,3` had end angle atan2(0,0) = 0 and so became a FULL circle in the
#    XY plane: a closed path, refused. A full QUARTER arc in XZ is refused too: its end tangent lies in the profile plane, so the
#    cap plane is parallel to the sweep - kernel test ExtrudeAlongCurve...RationalPath...)
#  3 open profile (a vertical line z=0..3) round a closed circle path r=2, Solid=Yes: periodic sheet, area 2 pi 2 3 = 37.6991
#  4 closed circle profile round a closed circle path, Solid=Yes: refused (zero net volume), nothing built
#  5 circle profile (XY) along a path inside its own plane, Solid=Yes: refused (flat), nothing built
#  6 control, no Solid option: unchanged ON_SumSurface surface, no kernel message
