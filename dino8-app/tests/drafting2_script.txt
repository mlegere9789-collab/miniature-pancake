# --- Associative DimAngle: anchored to three real Point objects (vertex +
# two direction points) via coincident-point matching, same rule as
# DimLinear. Placed in an unused part of the plane (500,500 area) so
# FindPointAnchor can't accidentally match an earlier object's coincident
# corner/endpoint instead of these. Moving one direction point from
# (500,510,0) to (510,510,0) changes the angle between (1,0,0) and the new

# as 45, not the original 90.
