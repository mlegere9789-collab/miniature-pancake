# Exact curved-solid QC (see the "SX" section at the end of smoke.sh).
#
# Audits and closes the "Solid editing with B-rep results (booleans, fillet,
# shell, offset)" bullet: every case below starts from `New` (so object ids
# restart at 1: operands are 1 and 2, a Boolean result is 3) and is bracketed
# by a marker line (an unknown command, "SXBEGIN_<name>") that smoke.sh uses to
# slice this script's output into per-case blocks. Each case ends with List
# (polysurface vs mesh, face/edge counts, closed solid), Volume and Area, so the
# smoke checks read measured numbers against closed-form values.
