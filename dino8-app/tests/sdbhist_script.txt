# History rebuild of a recorded SubD boolean replays the Levels option (the "SDH_" section, tests/sections/83_sdbhist.sh).
#
# With History On the boolean is recorded with its operands and its parameters; moving an operand re-runs it (no UpdateHistory needed). The typed
# Levels option is now a recorded parameter ("levels", editable with EditHistory), so the rebuild uses it instead of the automatic value.
# Fixture 1: two fully creased SubD boxes A = [0,10]^3 and B = [5,15]^3 (ids 1 and 2), BooleanIntersection = the box [5,10]^3 = 125 (id 3).
#   Moving B by (-2,0,0) makes B = [3,13] x [5,15] x [5,15]: the overlap is 7 x 5 x 5 = 175, and the rebuilt cage is still exact (rounds 0).
# Fixture 2: two smooth boxes, BooleanDifference with Levels=2 (rounds first 2, second 2); a Move rebuild must say 2 again (before: the automatic 3);
#   EditHistory 3 levels=1 rebuilds with 1 round.
