# Sweep2 with SEVERAL cross-sections on CLOSED rails and on rails that TOUCH at
# their ends -> the kernel's exact Brep::Sweep2Sections (cyclic sweep with a
# wrapped skin; degenerate end rows). Driven by smoke.sh's S2C_ section, which
# cuts the output apart per case at each "Command: Sweep2" line.
#
#   A  two concentric circles r = 5 and r = 8 (z = 0) and three straight radial
#      sections at 30, 150 and 270 degrees: the flat annulus, area
#      pi (8^2 - 5^2) = 122.52 (the closing segment 270 -> 390 crosses rail 1's seam).
#   B  the same rails with three different ARCHED radial sections (control
#      heights 1, 4 and 2): sections reproduced, wall edges on the rings, the
#      tallest arch (4 / 2 = 2) in the bounding box.
#   C  rails that meet at both ends (quadratic Beziers from (0,0,0) to (10,0,0) with control points (5,+-4,0), y = +-8 t (1 - t)), and
#      three straight sections across: the flat lens, area
#      2 * int y dx = 2 * int_0^1 8 t (1 - t) 10 dt = 160 / 6 = 26.667.
#   D  the same rails with three ARCHED sections (control heights 1, 3, 1).
#   E  negative control: three sections whose rail-2 ends swap places round
#      the closed rails (anchors cross) must still be refused, reason printed.
#   F  a long straight run into a tight bend (cubic rails 0..100 straight, then a
#      4 x 4 bend): 128 stations leave the wall edges 0.0165 from the rails, so
#      the command's retry ladder must reach 256 stations (edges within 2.44e-4).
#   G  rails with a tangent jump (polyline corner): more stations do not help
#      (0.0108 at 512), so the command must say so and fall back.
