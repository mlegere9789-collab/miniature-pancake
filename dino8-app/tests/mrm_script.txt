# Several rims of one solid of revolution blended exactly in ONE run (the "MRM_" section at the end of smoke.sh).
#
# FilletEdge now stages every revolve rim picked on the same solid and applies them together at Enter through
# kernel::FilletRevolveRims (one exact rebuild, each rim with the radius current at its pick; cmd_fillet.cpp
# TryRevolveRimsFillet); ChamferEdge applies each exact kernel bevel as it is picked, and the kernel now also reads back
# the torus blends / bevel cones its own earlier calls made, so rims can follow one another across runs as well.
#
# The solid is the app's own chamfered cylinder (see rvr_script.txt): radius 5, height 4, top rim chamfered 1 x 1, a
# 4-face solid of revolution with the (rho, z) profile (0,0) (5,0) (5,3) (4,4) (0,4); V1 = 299.498. Rim circles are
# picked as 0,rho,z: (5,0) wall / bottom cap, (5,3) bevel / wall, (4,4) bevel / top cap.
#
# Every case starts from `New` and is bracketed by a marker line ("MRMBEGIN_<name>", an unknown command) that smoke.sh
# uses to slice this script's output into per-case blocks.
