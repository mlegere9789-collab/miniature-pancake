# ---------------------------------------------------------------- fallback: a union with NO closed B-rep. Box 1 = [0,10]^3 and box 2 = [5,15] x [5,15] x [0,10] overlap, so the union is a sealed B-rep (planar engine, 1000 + 1000 - 5*5*10 = 1750). Box 2 moved by (5,5,0) is [10,20]^2 x [0,10]: it meets box 1 only ALONG AN EDGE (x = y = 10, z 0..10), so the union has an edge shared by four faces: it is not a 2-manifold, and no closed B-rep solid of it exists (the planar engine throws 'an edge is shared by 3 or more faces', the general engine refuses with its typed 'an edge is claimed by 3 or more fragment loops (non-manifold result)'). The rebuild must fall back to the mesh boolean (volume 2 x 1000 = 2000 exactly), print that reason and List a mesh; Undo -> the sealed B-rep; Redo -> the mesh; moving back -> the sealed B-rep again.
