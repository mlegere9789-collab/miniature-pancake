Tutorials

Ten task-based walkthroughs, each with the exact command sequence to type. Every sequence below was run through the real Dino8 binary headlessly with --smoke N --script <file> and @expect_objects/ @expect_selected checks — the same mechanism tests/smoke.sh uses for the project's own regression suite — so what you see here is what actually happens, not an aspirational example. The scripts themselves live in dino8-app/docs/tutorial_scripts/; run docs/tutorial_scripts/run_all.sh to re-verify them against a freshly built Dino8 at any time.

1. First shapes and navigationverified: 01_first_shapes.txt

Create a box and a sphere, move one, copy it, rotate the copy, and undo your way back.

1
Box

Click two corners in the Top view, then type 5 for the height. This is object 1.

2
Sphere

Click a center point off to the side, then a radius. This is object 2.

3
Select the box, then Move

Click the box (or type SelID 1), run Move, click a base point and a target point.

4
Select the box again, then Copy

Run Copy, click a base point, then a target point, then press Enter to stop copying (Copy will keep placing more copies if you keep clicking).

5
Select the new copy, then Rotate

Click a pivot point, then type an angle in degrees (or click a second point to set the angle visually).

6
Undo twice

The rotate and the copy both disappear, in reverse order, leaving the box and sphere as they were after the move.

Box                       (click, click, type 5)
Sphere                    (click, click)
SelID 1
Move                      (click base, click target)
Copy                      (click base, click target, Enter)
SelID 3
Rotate                    (click pivot, type 45)
Undo
Undo

2. Model a simple bracketverified: 02_bracket.txt

A flat plate, a mounting hole cut clean through it with a boolean, and one rounded corner — the basic pattern behind most mechanical parts.

1
Box

A 40 × 20 × 5 plate: click 0,0,0, then 40,20,0, then type 5 for the thickness.

2
Cylinder

A hole tool taller than the plate and centered where you want the hole, e.g. base point 10,10,-1, radius 2, height 7 (so it pokes through both faces).

3
Select the plate, run BooleanDifference, then select the cylinder

Click the plate first (or SelID 1), start BooleanDifference, then click the cylinder and press Enter. The cylinder disappears, leaving a clean hole through the plate.

4
FilletEdge

Type Radius=3, then click a vertical corner edge of the plate (click the middle of the edge, not a face), then Enter.

Run Volume on the result any time to confirm it is still a closed, valid solid.

Box 0,0,0 40,20,0 5
Cylinder 10,10,-1 2 7
SelID 1
BooleanDifference
SelID 2
Enter
FilletEdge
Radius=3
                          (click the corner edge)
Enter

3. Set up a renderverified: 03_render_setup.txt

Assign materials to a couple of objects, add a light and a ground plane, then render a still image to a file.

1
Build something to render

A Box and a Sphere is enough.

2
Select the box, run RenderAssignMaterialToObjects

e.g. Plastic Color=220,60,50 Gloss=0.7. Repeat on the sphere with a different material, e.g. Glass Color=200,225,240 Transparency=0.6 Reflectivity=0.3.

3
PointLight

Click (or type) a position above and to the side of the scene, e.g. 10,-30,40 Intensity=1.5.

4
GroundPlane On

Optionally set a Color= for it.

5
Render

Type the pixel width and height, e.g. Render 1280 720.

6
SaveRenderWindowAs

Type a path ending in .bmp or .ppm to write the rendered image to disk.

Box 0,0,0 20,20,0 10
Sphere 35,10,8 8
SelID 1
RenderAssignMaterialToObjects Plastic Color=220,60,50 Gloss=0.7
SelID 2
RenderAssignMaterialToObjects Glass Color=200,225,240 Transparency=0.6 Reflectivity=0.3 Gloss=0.9
PointLight 10,-30,40 Intensity=1.5
GroundPlane On Color=150,158,168
ZoomExtents
Render 1280 720
SaveRenderWindowAs myrender.bmp

Honest limitation

This is a CPU-only path tracer with no GPU acceleration or denoiser — expect it to be slower than Rhino's Cycles-based Raytraced mode at the same resolution/quality. See Coming from Rhino.

4. Organize a model with layersverified: 04_layers.txt

Create named layers, put new geometry on the current layer automatically, move existing objects between layers, and toggle visibility/locking.

NewLayer Structure
NewLayer Fixtures
SetLayer Structure
Box 0,0,0 20,20,0 10          (goes on Structure - it's now current)
SetLayer Fixtures
Sphere 30,10,5 5               (goes on Fixtures)
SelID 1
ChangeLayer Fixtures           (move the box onto Fixtures too)
SelAll
LayerOff                       (turns off every layer your selection is on)
AllLayersOn                    (brings everything back)
SelAll
LayerLock                      (locks the layers of the selected objects)
LayerUnlock                    (unlocks every layer)

The Layers panel on the right shows the same state graphically: click the eye icon to toggle visibility, the lock icon to toggle locking, and double-click a layer to make it current.

5. Parametric array with Dino Flowverified: 05_flow_array.txt

Dino Flow is Dino 8's node-based visual scripting editor (its Grasshopper-class tool). This walkthrough builds a tiny graph that arrays a box along a line, driven by a numeric slider, and bakes the result into the document as real objects.

1
Type Grasshopper

Opens the Dino Flow node editor panel.

2
Add a Number Slider node

Params > Input > Number Slider. Set it to integer mode, range 1–12, value 6 — this will drive how many copies the array makes.

3
Add a Box node

Surface > Primitive > Box. Leave its Base at the origin and set X/Y/Z to 4 each — a 4-unit cube.

4
Add a Linear Array node

Transform > Array > Linear Array. Wire the Box's output into its Geometry input, and the slider's output into its Count input. Leave Direction at (1,0,0) and Distance at 6.

5
Add a Bake node

Output > Document > Bake. Wire the Linear Array's output into it, set Layer to Default and Name to FlowArray.

6
Drag the slider (or click Bake)

Watch the count of boxes in the viewport change live as you move the slider, then bake to add the six real box objects to the document.

To run a saved graph like this one from the command line instead of building it by hand — useful for batch generation — use GrasshopperPlayer:

Grasshopper
GrasshopperPlayer path/to/graph.dflow Bake=Yes

Honest limitation

Dino Flow does not yet have Grasshopper's data-tree semantics (lists/graft/flatten) or a solver/optimizer node family, and there is no third-party node marketplace. See Coming from Rhino.

6. Block out a roomverified: 06_arch_room.txt

Dino 8's architecture commands build parametric walls with real cut openings for doors and windows, plus floor slabs and roofs.

1
Wall

Wall 0,0,0 5,0,0 2.4 0.2 — start point, end point, height 2.4, thickness 0.2 (a 5-unit wall, 2.4 tall).

2
Select the wall, run Door

Door 2.5,0,0 0.9 2.1 — a door centered at x=2.5, 0.9 wide, 2.1 tall, cut directly into the wall's mesh.

3
Select the wall again, run Window

Window 4,0,0 1.2 1.2 0.9 — center, width, height, sill height above the floor.

4
ArchSlab

ArchSlab 0,-3,0 5,0,0 0.2 — two corners of a footprint and a thickness, for a floor slab.

Every edit to a wall (adding a door, then a window) rebuilds its mesh and gets a new object id — reselect with SelLast right after creating or editing it rather than remembering a specific id.

Wall 0,0,0 5,0,0 2.4 0.2
SelLast
Door 2.5,0,0 0.9 2.1
SelLast
Window 4,0,0 1.2 1.2 0.9
ArchSlab 0,-3,0 5,0,0 0.2

Also available: Roof (gable/hip roofs over a footprint) and Stair (a run of risers between two points).

7. Sketch and revolve a vaseverified: 07_revolve_vase.txt

Draw half of a profile curve in the Front view, then spin it 360° around a vertical axis to build a surface of revolution.

1
InterpCrv

Click several points up one side of where you want the vase's silhouette (e.g. a wide base narrowing then flaring at the lip). The curve passes exactly through each point.

2
Select the curve, run Revolve

Click the start of the revolve axis, then the end — a vertical line running through the curve's base, e.g. from 0,0,0 to 0,20,0.

The profile curve stays in the document alongside the new revolved surface, so you can tweak its control points (F10) and re-run Revolve to iterate.

InterpCrv 0,0,0 3,4,0 2,8,0 4,12,0 0,14,0
SelLast
Revolve
                          (click 0,0,0, then 0,20,0 for the axis)

8. SubD basicsverified: 08_subd_basics.txt

SubD (subdivision surface) modeling gives you a low-poly control cage that displays as a smooth surface. This walkthrough creases an edge (so it displays sharp instead of smooth), extrudes a face, and converts the result to NURBS.

1
SubDBox

Same syntax as Box — two corners and a height.

2
Select the SubD, run Crease

Click the midpoints of one or more control-cage edges to mark them sharp, then Enter.

3
ExtrudeSubD

Click the centroid of a face to extrude it, then type a distance.

4
Select the SubD, run ToNURBS

Adds a separate NURBS/B-rep copy of the SubD to the document — the original SubD is untouched, so you keep editing the SubD cage and re-convert whenever you like.

SubDBox 0,0,0 10,10,0 10
SelLast
Crease
                          (click one or more edge midpoints)
Enter
SelLast
ExtrudeSubD
                          (click a face centroid)
3
SelLast
ToNURBS

Other SubD tools worth knowing: Inset, Bridge (joins two SubD faces with a tube), OffsetSubD Solid=Yes (shells it), RepairSubD.

9. Save, export, and reopenverified: 09_save_export.txt

The file workflow you will use constantly: native save for round-tripping your own work, export for handing geometry to another tool.

Box 0,0,0 10,10,0 10
Sphere 30,0,0 5
Save mymodel.3dm
SelAll
Export mymodel.stl
New
Open mymodel.3dm

Save/Open round-trip layers, object names, colors, user text, notes, named views, and units losslessly through native .3dm. Export supports OBJ, STL, STEP/IGES, DXF, PDF, PLY, and SVG depending on the objects selected; Import brings another file's objects into the current document without closing it.

10. Draft, fillet, and extrude a profileverified: 10_profile_extrude.txt

The classic 2D-to-3D workflow: draft a closed 2D outline, round its corners, then push it into a solid.

1
Rectangle3Pt

Click one corner, then a point along one edge, then a point along the perpendicular edge — this lets you draw a rectangle at any angle, not just axis-aligned.

2
Select it, run FilletCorners

Type a radius, e.g. 2 — every corner of the closed curve gets rounded in one pass.

3
Select the curve (SelCrv selects every curve), run ExtrudeCrv

Type a height. Because the profile is closed and planar, the result is a capped solid, not just a wall surface.

Rectangle3Pt 0,0,0 20,0,0 0,10,0
SelLast
FilletCorners
2
SelCrv
ExtrudeCrv 8

cmake --build dino8-app/build --parallel
