# Automatic history propagation, part 2 (cmd_history.cpp HistoryAutoUpdate):
# the OTHER ways a source object is edited - Rotate, Mirror (in place), a
# non-uniform ScaleNU, and a boolean OPERAND moved directly - plus Undo/Redo
# consistency. No UpdateHistory anywhere. Every claim is a measured Volume.
# (BoundingBox, VolumeCentroid & co CREATE objects in this app, which would
# clear the Redo stack and shift the ids, so only Volume is used here.)
