# AutoLISP-style Lisp dialect (src/script/Lisp.cpp, commands/cmd_lisp.cpp).
# Every expression is typed on the command line exactly as a user would. The
# smoke.sh section (LSP_) compares each result with an independently computed
# value, drives real commands through (command ...) and reads the document
# back with Volume / Length / object counts, and runs the negative controls
# (syntax errors, run-time errors, refused redefinitions, runaway loops).
# @TMP@ is replaced by smoke.sh. Object ids are the deterministic 1-based counter.
