# Registry-based construction history (cmd_history.cpp, history_rebuild.h):
# every construction whose result comes from an exact kernel call records its
# source objects + numeric options, and UpdateHistory re-executes it through ONE
# dispatch table, in dependency order. This script MOVES/SCALES an input and
# checks the dependent result's MEASURED geometry (Volume / Area / Length /
# bounding box), never just an object count:
#   S1  curve -> Extrude -> BooleanIntersection (a 2-deep chain), Undo/Redo of
#       the UpdateHistory
#   S2  curve -> Extrude (x2) -> BooleanUnion, Undo/Redo of the boolean itself
#   S3  BooleanDifference and Boolean2Objects
#   S4  failure: the root curve of a chain is deleted -> reason printed, the
#       dependents keep their geometry
#   S5  History Off is respected (no record, operands deleted as before), and
#       a record made while On survives History being turned Off
#   S6  the other newly recorded constructions: PlanarSrf -> ExtrudeSrf (a
#       2-deep chain), ExtrudeCrvTapered, ExtrudeCrvAlongCrv, NetworkSrf (4 and
#       3 curves), EdgeSrf, RailRevolve, Offset, OffsetSrf
# Object ids are the deterministic 1-based counter Document::Add assigns, in
# creation order (a hidden boolean operand still owns its id). Each section ends
# with Hide-all + HistoryPurge so the next section's UpdateHistory only sees its
# own records.
