# FilletEdge / ChamferEdge record construction history (tests/smoke.sh section H2R_).
# With History On an exact planar fillet / chamfer hides the solid it was applied
# to (instead of editing it in place) and records {source, radius or distances,
# one geometric signature per edge}. Editing the source then rebuilds the result
# automatically: each recorded edge is re-found by direction + both face normals
# (+ position relative to the solid's bounding box). Every claim below is a
# measured Volume or Bounding box, compared in smoke.sh with the SAME operation
# performed fresh on the moved/scaled source (the "control" boxes).
# @TMP@ is the test temp directory.
SetActiveViewport Top
