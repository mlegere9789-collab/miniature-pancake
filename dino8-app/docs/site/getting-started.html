Getting started

This page assumes no prior 3D modeling experience. If you have used Rhino before, look for the Rhino tip boxes — the rest still applies to you.

1. Install

Grab the installer for your platform (Dino8Setup-*.exe on Windows, a .deb or .tar.gz on Linux, a .dmg on macOS) from the project's releases, or build it yourself:

cmake -S dino8-app -B dino8-app/build -DCMAKE_BUILD_TYPE=Release
cmake --build dino8-app/build --parallel
dino8-app/build/Dino8

On Linux you need the OpenGL/X11 development headers: libgl1-mesa-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev. Dependencies (GLFW, Dear ImGui, OpenNURBS, Manifold) are fetched automatically by CMake.

Nothing phones home

No account, no license key, no telemetry, no update nag. Settings are stored locally (%APPDATA%\Dino8 on Windows, ~/.config/dino8 on Linux, ~/Library/Application Support/Dino8 on macOS).

2. The screen layout

On first launch you will see:

  • Four viewports (Top, Front, Right, Perspective) filling most of the window.
  • A toolbar across the top with icon buttons for common commands.
  • A command line just under the toolbar — this is the fastest way to do anything in Dino 8, and the rest of this guide leans on it.
  • Layers and Properties panels docked on the right.
  • A Command History panel at the bottom, showing everything you have typed and every message the app has printed back.
  • Object snap and grid/ortho toggles along the very bottom (status bar).

Every panel can be dragged by its tab to re-dock or float it, and the layout is remembered between sessions.

3. The command line, in one minute

Almost everything in Dino 8 is a command: a short, typed word that starts an operation, which then asks you for the input it needs (usually points you click in a viewport, sometimes a typed number). You never have to memorize menus.

  1. Click in the command line (or anywhere in a viewport) and type Box, then press Enter.
  2. The command line now prompts First corner of base. Click a point in the Top viewport.
  3. It prompts Other corner of base. Click a second point.
  4. It prompts for a height. Type 10 and press Enter (or click a third point to set the height visually).

You now have a box. Press Esc at any point during a command to cancel it, and press Enter on an empty command line to repeat whatever command you last ran — useful for placing several boxes in a row.

Rhino tip muscle memory carries over

Dino 8 deliberately uses Rhino 8's own command names, aliases, and prefixes: type b for Box, c for Circle, l for Line, co for Copy, m for Move; prefix with _/-/! for macros exactly like Rhino; type relative coordinates as @5,0 and polar coordinates as 20<45. The full alias list and every command's exact option syntax is on the Command Reference page.

Typing coordinates

What you typeMeaning
10,5,0An absolute point in world coordinates (x, y, z)
@5,0A point 5 units in x, 0 in y, relative to the last point you placed
20<45A point 20 units away at a 45° angle (polar) from the last point
a bare number, e.g. 10A distance along the direction your cursor is currently pointing

Command-line options

Many commands offer options while they run — for example, typing Box then clicking Deformable or setting NumSides=8 before completing a Polygon. Options appear as clickable words after the prompt; you can click them with the mouse or type the option's name (and, for a value option, the new value) on the command line.

Useful toggles, all in the status bar or on function keys: F7 grid, F8 ortho (snap to 0/90/180/270°), F9 grid snap, F10 turns on control points for the selected curve/surface, Home resets the active view. Object snaps (End, Mid, Cen, Quad, Near, Vertex) live in the status bar and make your clicks land exactly on existing geometry.

5. Your first few shapes

Try these directly on the command line, one at a time:

  • Box, Sphere, Cylinder, Cone, Torus — solid primitives.
  • Line, Circle, Arc, Rectangle, Polygon — curves you can later extrude, revolve, or loft into surfaces.
  • Move, Copy, Rotate, Scale, Mirror — select an object first (click it, or type SelLast right after creating it), then run the transform.
  • Drag the Gumball that appears on a selected object instead of typing: arrows move it, the rings rotate it, the small cubes scale it. Hold Shift for 15° rotation steps or uniform scaling.

When you are ready for full worked examples with exact command sequences, move on to the Tutorials page — every sequence there has been run through the real application to confirm it produces the stated result.

6. Saving your work

Save and Open read and write native .3dm files (round-tripping layers, names, colors, user text, notes, named views, and units). Export and Import handle OBJ, STL, STEP/IGES, DXF, and more. Undo (Undo, alias u) snapshots the whole document on every change, so it can never desync from what you actually did — press it as many times as you like.
