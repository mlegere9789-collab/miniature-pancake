First shapes

Beginner · 1:44 · 11 narration cues

Draw a box and a sphere, move and copy them, rotate, and undo - the basic loop of every Dino 8 session.

Transcript
  1. 0:00Welcome to Dino 8. This is the empty workspace: four viewports, the command line at the top, and the object snaps along the bottom.
  2. 0:10Every action in Dino 8 is a command. We make the Top view active so the points we type land on the ground plane.
  3. 0:20The Box command takes two opposite corners and a height. Corners 0,0,0 and 10,10,0, five units tall. One object now exists in the document.
  4. 0:30A sphere takes a centre and a radius. It sits to the right of the box, and the document now holds two objects.
  5. 0:40Objects are selected by clicking, or by a command. Here we select the box by its identifier, number one.
  6. 0:48Move takes a start point and an end point. The box slides five units in X and five in Y.
  7. 0:58List prints what is selected to the command history, so you can always check what a command really did.
  8. 1:07Copy works like Move but leaves the original behind. Pressing Enter ends the command, and we have three objects.
  9. 1:17Rotate takes a pivot point and an angle in degrees. The copy turns forty-five degrees about its own corner.
  10. 1:27Nothing is permanent. Two Undos step back through the rotate and the copy, and we are down to two objects again.
  11. 1:36That is the whole loop: pick a command, give it points, press Enter. The next tutorial covers selection and snaps.

Selection and snaps

Beginner · 1:37 · 11 narration cues

Pick objects with the mouse, window and crossing selections, selection commands, and object snaps that lock clicks onto exact points.

Transcript
  1. 0:00This tutorial is about two things: choosing objects, and clicking exactly where you mean. First, a small scene to work with.
  2. 0:14Two boxes, a circle and a line. Nothing is selected yet.
  3. 0:19Clicking an object in a viewport selects it. The click landed on the edge of the first box, and the Properties panel now describes the selection.
  4. 0:30A window selection takes only the objects completely inside the rectangle. Both boxes qualify, the circle and line do not.
  5. 0:40A crossing selection takes everything the rectangle touches. This one reaches the circle and the line.
  6. 0:47Commands can select by type. SelCrv picks every curve in the document, so the circle and the line.
  7. 0:55Invert flips the selection, leaving the two boxes selected instead.
  8. 0:59Now snaps. End, Mid and Cen are on. Watch the Osnap bar: a click near an endpoint, midpoint or centre jumps to that exact point.
  9. 1:09We clicked slightly off the line's left end and slightly off the circle's centre. The new line starts and ends exactly on them.
  10. 1:20Length confirms it. A line from 0,40 to 15,25 is exactly twenty-one point two one units, with no rounding from where the mouse happened to be.
  11. 1:30Selection chooses what a command acts on, and snaps choose where. Together they cover most everyday modelling.

Organize with layers

Beginner · 1:25 · 10 narration cues

Create layers, draw on the current layer, move objects between layers, hide, show and lock them.

Transcript
  1. 0:00Layers keep a model manageable. The Layers panel on the right lists them; right now there is only the Default layer.
  2. 0:11NewLayer adds a layer by name. We create two, Structure and Fixtures, and both appear in the panel.
  3. 0:19SetLayer makes Structure the current layer. Anything we draw from now on lands on it, like this box.
  4. 0:28Switch the current layer to Fixtures and draw a sphere. The panel's object counts track each layer.
  5. 0:36Changed our mind? ChangeLayer moves the selected box onto Fixtures. Both objects now share one layer.
  6. 0:43List reports the layer name for each object, a quick way to confirm the move.
  7. 0:51LayerOff hides the layer of every selected object. Select all again and nothing is selected, because everything on that layer is hidden.
  8. 1:02AllLayersOn brings every layer back, and both objects can be selected again.
  9. 1:09LayerLock locks the layer: its objects stay visible and snappable but can no longer be selected or edited by accident.
  10. 1:17LayerUnlock releases it. Layers are the simplest way to keep order in a model as it grows.

Extrude and revolve a vase

Beginner · 1:02 · 6 narration cues

Sketch a smooth profile, revolve it into a vase, then extrude a round foot - the two most useful solid-making commands.

Transcript
  1. 0:00A vase is a profile spun around an axis. We sketch the profile first, using the Top view with the height typed as Z so it lies in the vertical plane.
  2. 0:14InterpCrv draws a smooth curve through the points we give it: base, belly, neck and lip. Enter finishes the curve.
  3. 0:23Revolve takes the selected curve, then two points that define the axis. The curve sweeps a full turn and a vase surface appears.
  4. 0:35Switch to the Perspective view and maximize it to see the vase in three dimensions.
  5. 0:43Extrude is the other workhorse. A circle selected and extruded two units becomes a solid disc, here a foot for the vase.
  6. 0:54Revolve and Extrude both leave the source curve in place, so you can edit it and make the shape again.

Booleans on a bracket

Beginner · 1:16 · 8 narration cues

Build a mounting bracket from a plate, a hole, a rib and a slot using boolean difference and union.

Transcript
  1. 0:00Boolean operations add and subtract solids. We will build a small mounting bracket: a plate, a screw hole, a stiffening rib and a slot.
  2. 0:11The plate is a box forty by twenty, five units thick.
  3. 0:16A cylinder of radius two, taller than the plate, will become the screw hole. It starts below and ends above the plate so the cut is clean.
  4. 0:29BooleanDifference subtracts the second object from the first. The cylinder is consumed, and Volume reports the plate minus the hole.
  5. 0:38A rib: a thin box standing along one long edge, overlapping the plate by one unit so the two solids truly share volume.
  6. 0:48BooleanUnion fuses everything selected into one solid. Plate and rib are now a single part.
  7. 0:59Finally a slot, cut with another box in the same way. Select the part, run BooleanDifference, then pick the cutter.
  8. 1:08Three booleans, one finished bracket. The volume readouts in the command history show each step really removed or added material.

Fillets and chamfers

Intermediate · 1:21 · 8 narration cues

Round one edge with FilletEdge and bevel another with ChamferEdge, and check the volume change numerically.

Transcript
  1. 0:00Sharp edges rarely survive in real parts. Fillets round an edge and chamfers bevel it. We will use both, on two identical blocks.
  2. 0:13Two ten-unit cubes side by side. Each has a volume of one thousand cubic units.
  3. 0:21The first cube will get a fillet. Volume confirms we start at exactly one thousand.
  4. 0:28FilletEdge asks for a radius and then for an edge to round. We set Radius to two, then point at the middle of one vertical edge. Enter accepts.
  5. 0:42A rolling ball of radius two rounded the edge, so the volume dropped to nine hundred ninety-one point four cubic units.
  6. 0:51ChamferEdge works the same way, but cuts a flat bevel instead of a curve. Distance two on each face.
  7. 1:01A bevel of distance two on a ten unit edge removes two times two over two, times ten, which is exactly twenty cubic units. Nine hundred eighty remain.
  8. 1:12Use fillets where a smooth, flowing surface or stress relief matters, and chamfers where you want a cheap, crisp, machinable bevel.

SubD basics

Make a subdivision-surface box, crease an edge, extrude a face, and convert the result to exact NURBS.

Transcript

  2. 0:11SubDBox makes a ten unit cube as a SubD. Note how soft it looks: the corners are rounded by the smoothing.
  3. 0:23A crease keeps an edge sharp. We select the box, run Crease, and pick the edges we want to keep crisp.
  4. 0:33What describes the selection, which is now a SubD with a creased edge.
  5. 0:40ExtrudeSubD pulls a face outward. We pick the top face and extrude three units, and the smoothing reshapes the whole form around it.
  6. 0:51When you need exact geometry, ToNURBS converts the SubD to a NURBS surface. The SubD stays, so you can keep editing the original.

Dimension a part, then lay it out on a print sheet with a detail view and a title block.

Exporting and printing

Beginner · 1:19 · 8 narration cues

Save the model, export it for 3D printing as STL and for other tools as OBJ, and print the drawing to PDF.

Transcript
  1. 0:00Getting a model out of the program: for the printer, for other software, and onto paper. We start with a small part to export.
  2. 0:15A block with a round boss on top, fused into one solid.
  3. 0:20Save writes a native 3dm file, which keeps everything: layers, units, history. Always save this first.
  4. 0:28Export picks the format from the file extension. STL is what most slicers want for 3D printing: select the part and export. The solid is saved as a triangle mesh.
  5. 0:40OBJ is a widely understood mesh format for rendering and game tools. The same selection, a different extension.
  6. 0:49Print writes a vector PDF of the active view. Because the lines are vectors, the drawing stays sharp at any print size.
  7. 0:59To prove the save worked, start a new empty document and open the file again. The part comes back exactly as we left it.
  8. 1:09Before you send an STL to a printer, check the part is a closed solid and its units are what the slicer expects.
