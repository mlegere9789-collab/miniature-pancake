# G0: Independence charter (draft for counsel)

**Status:** draft. Counsel approval is required before any public release. This is a process proposal, not legal advice.

## Purpose
Produce an original game whose code, art, audio, animation, data and text are independently created or properly licensed, with an evidence
trail showing how each piece was made.

## Input tiers
- **Forbidden:** any code, data, model, texture, sound, UI art, text or schema extracted from, or copied from, another publisher's strategy game
  or its mod ecosystem; decompiled binaries; leaked material.
- **Restricted:** documents that describe another product's mechanics (analyses, audits, formula write-ups). Kept in the reference environment
  (`/audits/`); they reach specs only as sanitised abstract notes through gate G2.
- **Permitted:** historical sources, public-domain texts and images, engine and computer-science documentation, open-licence libraries under
  tracked licences, this project's own prototypes.
- **Preferred:** the historical record and calibration of the simulation against documented outcomes.

## Environments
- **R reference:** sessions that have read Restricted material. Never used to write product code.
- **S/I build:** fresh sessions given only specs, datasets and permitted material; allowlisted network.
- **A audit:** scans and red-team; holds the forbidden-terms extras; never writes product code.
- **L legal:** humans only.

## Gates
G0 charter, G1 input approval, G2 sanitisation (also covers datasets leaving R), G3 spec release, G4 code and data (every merge: similarity,
licence and forbidden-terms scans), G5 asset provenance, G6 milestone legal review, G7 release clearance (trademark, patent landscape,
compliance, AI-disclosure rules).

## Commitments
- Original vocabulary and schemas grounded in period terms; original UI.
- Every artefact has a provenance manifest; independent-creation dossiers per major system.
- Meaningful human authorship for key creative assets; consenting, fairly paid performers; licensed or indemnified generators only.
- Contamination response: stop, quarantine, preserve evidence, assess with counsel, rebuild from the clean spec with fresh sessions, fix the
  process, never edit logs.
- Counsel and a patent landscape search happen at the start (P0/P1), not at the end.

## Open questions for counsel
Persuasiveness of this process given model training exposure; handling of the audit documents; patent exposure for genre mechanics; rules for
AI-generated assets by market; performer and advisor contracts; period imagery and symbols by region; whether the placeholder title needs
replacing before any public use.
