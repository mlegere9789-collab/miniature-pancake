# audits/ (reference environment, not part of the game)

These files audit two research PDFs. They describe a third party's product and contain
reference-game material, so under the clean-room plan they are **Restricted**: build
and implementation sessions must never read them. Only the game directory
(`a-house-divided/`) is the product. The scanners in `a-house-divided/tools/` never
exempt this folder from review of what crosses into the product.
