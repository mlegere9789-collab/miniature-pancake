# reopens the exported file in a fresh document: each reimported dimension
# must carry the exact same Annotation/DimP0/DimP1/DimOffset (for the

# leader) tags DxfImporter::Dimension()/Leader() already write for a

# readers' own comments document), proving the new writers and the
