# Two parallel vertical lines 20 units apart (x=800 and x=820, y 0..10);
# CenterLine's midline runs x=810, y 0..10. A dedicated NewLayer (made
# current, so both new lines land on it and nothing else does) plus
# SelLayer selects exactly these two lines for CenterLine's 2-object pick -
# corrected 2026-09-30, was a hardcoded SelID pair that had drifted stale:
# a *wrong-but-real* id is accepted by SelID without complaint (unlike a
# truly invalid one, which at least warns), so a stale pair fails quietly
# with the wrong midline instead of an obvious error, and when both ids
# happen to resolve to nothing at all (as this one had) CenterLine's own
# WantObjects(2) never gets satisfied and it sits waiting for more picks,
# silently swallowing every subsequent script line as an object pick/point
# instead of a command - no-op'ing everything below it, including this
# file's own later checks. A per-block layer sidesteps id-counting
# entirely.

Line 800,0,0 800,10,0
SelLast
SetObjectName CenterLine1
Line 820,0,0 820,10,0
SelNone
SelLayer
CenterLine
SelNone

# --- Dimension styles: real units/precision, a unit suffix and a default
# tolerance, wired into the actual dimension-building code (DimStyleParams,
# DimGeometry.h/annotate_common.h) - not stored-and-ignored fields.
# DimStyle1's Precision=2/Suffix=mm/TolMode=symmetric bakes "100.00 mm" plus
# a "+/-0.05" tolerance suffix for a dimension measuring exactly 100 units,
# not the old unstyled "100". SelLast/GetUserText reads the baked "Text"
# user-text tag back from just the new dimension's own glyph (SelLast, not
# SelDim - selecting every dimension built earlier in this already-long
# script and dumping all of their user text made $A2 large enough to hit a
# real, separate smoke.sh bug: `echo "$A2" | grep -q` under this script's
# own `set -o pipefail` can report a spurious failure for a match that
# occurs early in a large piped string, since grep -q's early exit once it
# finds that match can SIGPIPE the still-writing `echo` before it finishes,
# and pipefail then surfaces that SIGPIPE as the whole check's exit status -
# so every later a2check call in the script read as a false FAIL. Fixed
# here by keeping the selection - and so GetUserText's output - small,
# rather than touching the shared a2check/near helpers every other script
# section's checks also rely on).
AnnotationStyles Name=DimStyle1 Precision=2 Suffix=mm TolMode=symmetric TolValue=0.05 Current=Yes
Dim
