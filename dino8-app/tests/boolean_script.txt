# Boolean QC: BooleanUnion/BooleanIntersection, Boolean2Objects (Result
# cycling through Union/Intersection/A-B/B-A/SymmetricDifference),
# BooleanSplit/MeshSplit/MeshBooleanSplit (both pieces kept), WireCut (one
# side kept, the other discarded), MeshSmooth (see smoke.sh). Two-set
# booleans need both objects created BEFORE the command starts (like
# BooleanDifference in smoke.sh's own inline script) - creating the second
# object WHILE the command is mid-selection would feed it to the command as
# text instead of running it, so ids are picked with explicit SelID/SelNone
# once both objects already exist (ids are assigned in creation order,
# 1-based, and are never reused even across an in-script Delete).
SetActiveViewport Top

SelAll
Delete
