# Sealed exact Booleans (see the "SBL_" section at the end of smoke.sh).
#
# The app's exact general-Boolean path now tries kernel::SealGeneralBooleanResult (the sewing half of
# BooleanCombineGeneralSealed) first: a result that seals is ON_Brep::IsValid + IsSolid with REAL inner loops
# (no keyhole slits) and an exact divergence-theorem volume. Every case starts from `New` (operands are 1 and 2,
# a Boolean result is 3) and is bracketed by an unknown-command marker SBLBEGIN_<name> that smoke.sh slices the
# output on. Each case runs Check, List, Volume and Area so the checks read measured numbers against closed forms.
