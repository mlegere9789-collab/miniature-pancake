# layer, with no way to define "Monochrome" once and assign it to several

# with no active plot style table must stroke black at the document

# SAME Line re-export red at 0.5mm - not its unchanged on-screen display
# color or the document default width; deactivating the table (None) must
# return to black at 0.25mm.
